# 发票 / 火车票 / 合同 批量重命名（纯前端版）

## 命名规则

| 类型 | 格式 | 示例 |
|---|---|---|
| 住宿/打车票 | `日期_销售方简写_购买方简写_类型_地点_金额元` | `2025-06-08_汉庭_腾讯_住宿费_北京_328元.pdf` |
| 飞机票/火车票/T3出行 | `日期_出发地_到达地_类型_金额元` | `2025-07-27_上海-杭州_火车票_553元.pdf` |
| 合同 | `签订日期_项目名称_甲方_乙方_金额元` | `2025-01-15_采购合同_腾讯_阿里_50000元.docx` |
| 普通发票 | `日期_销售方简写_购买方简写_金额元` | `2025-06-08_松鼠创科_广德_265.35元.pdf` |

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 + 第三方库引入 |
| `styles.css` | 完整样式（拖拽/表格/弹窗/Toast） |
| `app.js` | 主控制流（选择→识别→命名→导出） |
| `extractors.js` | 核心抽取（发票/火车票/T3出行/合同） |
| `filenames.js` | 命名规则（按用户四条规则） |
| `export.js` | CSV/Excel 导出 |
| `highPrecision.js` | 高精度后端桥接（可选） |
| `high_precision_server.py` | Python EasyOCR 后端（可选） |

## 修复内容

- **T3出行识别**：新增 T3出行/滴滴/曹操/高德/美团等网约车平台关键词检测，优先级高于火车票
- **飞机票识别**：修复飞猪等关键词被吞掉的问题
- **住宿地点提取**：住宿费类型支持提取地点字段
- **OCR 容错**：增强文本预处理，修复常见 OCR 误读
- **DOCX/DOC 支持**：合同和发票支持 Word 文档读取
- **拖拽增强**：修复拖拽区域点击和文件选择

## 部署

1. 把这 8 个文件上传到任意静态服务器（Cloudflare Pages、GitHub Pages、Replit 等）
2. 如需高精度模式，部署 `high_precision_server.py` 到 Python 服务器

## 使用

- 拖拽文件到蓝色虚线框，或点击"选择文件"
- 支持 PDF、JPG、PNG、BMP、DOCX/DOC
- 等待 OCR 识别完成（首次约 5 秒加载 Tesseract.js）
- 点击新文件名可手动编辑
- 下载 ZIP / CSV / Excel

## 技术栈

- Tesseract.js（OCR）
- PDF.js（PDF 渲染）
- mammoth.js（DOCX 解析）
- JSZip（ZIP 打包）
- SheetJS（Excel 导出）
- 纯原生 JS（无框架依赖）
